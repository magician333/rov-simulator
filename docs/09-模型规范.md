# 09 — 模型规范（GLTF / GLB）

> 供建模方/后续模型提供者阅读。所有外部模型放入 `public/models/`（构建后位于 `dist/models/`）。

## 1. 通用约定

| 项 | 约定 |
|----|------|
| 格式 | GLTF 或 GLB（`*.gltf` / `*.glb`），支持 Draco 压缩可选 |
| 单位 | 米（m），与场景/物理单位一致 |
| 轴向 | **Y 向上**，右手系 |
| 前向 | **-Z 为前方**（Three.js 惯例；ROV 模型前向 = -Z） |
| 比例 | 真实尺寸（ROV 长 1.2m、船舶长 40m 等） |
| 纹理 | 内嵌或外部引用均可；避免超大贴图（建议 ≤2K） |
| 面数 | 目标物/结构 ≤ 50K 三角；ROV 整机 ≤ 200K |

## 2. ROV 机型模型（`ROVConfig.model.type = 'gltf'`）

在 `src/core/rov/ROVConfig.ts` 中新增机型：

```ts
{
  id: 'my_rov',
  name: '我的 ROV',
  // ... 物理参数（推进器布局决定自由度）...
  model: { type: 'gltf', url: '/models/my_rov/model.glb' },
  lights: [{ id: 'main_light', position: [0, 0.2, -0.5], ... }],
  povOffset: [0, 0.2, -0.6],
}
```

### 2.1 锚点命名节点（模型内）

| 节点名 | 作用 | 必需 |
|--------|------|------|
| `light_{light.id}` / `light_main` | 补光灯挂载点（按此位置摆放 SpotLight 与发光球；节点位于原点时用 ROVConfig.lights 配置位置） | 可选 |
| `pov_cam` | 第一视角相机位置（覆盖 `povOffset`；位于原点时忽略） | 可选 |
| `thruster_1` ~ `thruster_N` | 推进器转子动画节点（每帧自转；需有实际位置偏移，原点标记节点不参与） | 可选 |

> 兼容约定：锚点节点可以只是**命名标记**（位于原点、几何自带位置），此时灯光/相机位置回退到 `ROVConfig` 配置；锚点带实际位置变换时优先使用锚点。

### 2.2 机械臂锚点（作业型 ROV）

| 节点名 | 作用 | 说明 |
|--------|------|------|
| `claw_left` / `claw_right` | 夹爪左/右夹头 | 抓取动画节点（未来夹爪开合/抓取动画驱动） |
| `claw_left_fixed` / `claw_right_fixed` | 夹头固定点（螺丝位置） | 标定夹爪闭合基准与抓取参考点 |
| `claw_center_fixed` | 夹爪中心固定点 | 机械臂末端基准 |

- 机械臂整体默认**深灰色材质**（模型未带材质时由引擎统一填充）；如建模方提供材质则优先使用。
- 夹爪动画暂未接入，锚点先用于视觉与后续抓取功能预留。

接入新 GLTF 机型的一般流程：

```ts
{
  id: 'my_rov',
  name: '我的 ROV',
  maxSpeedKnots: 4.5,
  maxSwaySpeedKnots: 2,      // 可选：侧向航速
  thrusters: 8,               // 推进器布局 → 自由度
  lights: [{ id: 'left', position: [...] }, ...],
  povOffset: [...],
  model: { type: 'gltf', url: '/models/ROV/my_rov.glb' },
}
```

- 机械臂夹头：`claw_left` / `claw_right`（夹爪），`claw_*_fixed`（螺丝固定点）
- 材质默认深灰色

### 2.4 模型预处理约定（重要）

建模方交付的 GLTF/GLB 若存在以下问题，需先运行预处理脚本（或建模方在 Blender 修正）：

| 问题 | 处理 |
|------|------|
| 面数过高（>20 万） | `scripts/decimate-gltf.mjs` 顶点聚类减面（改 `CELL` 常量调档） |
| 尺寸异常（非米/未缩放） | 烘焙缩放至真实尺寸（脚本 `SCALE`） |
| 机头方向非 -Z | 烘焙旋转使机头（相机/机械臂方向）朝 -Z（脚本 `ROT_X_90` 或自定义四元数） |
| 锚点节点位于原点 | 灯光/相机位置在 `ROVConfig` 中配置（引擎回退逻辑） |

- 模型规范：**前向 -Z**（机头/相机/机械臂所在方向）、单位米、Y 向上、根节点包含所有锚点子节点。
- 也可在 `ROVConfig.model` 中配置 `scale` / `rotation` 由引擎加载时应用（不修改模型文件）。

## 3. 场景模型（`SceneDefinition.gltfModels`）

在场景定义中声明外部结构模型（船舶、桥梁等），加载后按配置摆放：

```ts
// 例：船舶场景接入外部船体模型
gltfModels: [
  {
    name: 'ship_hull',
    url: '/models/scenes/ship_hull.glb',
    position: [0, -2.5, 0],
    rotation: [0, Math.PI, 0], // 面向学员
    scale: [1, 1, 1],
  },
],
```

- 场景程序化部分（目标物、标记环、碎石等）保留在 `build()` 中；
- 外部模型统一为"结构体"角色，**目标物标记仍在代码中挂**（`markTarget`）以便任务系统定位；
- 卸载场景时自动 `disposeObject` 并移除。

### 3.1 建议命名

```
public/models/scenes/ship_hull.glb
public/models/scenes/bridge_piers.glb
public/models/scenes/dam_face.glb
```

## 4. 自检清单（提供模型前）

- [ ] 单位是米、Y 向上、前向 -Z
- [ ] 模型不包含灯光/相机（由引擎动态挂载）
- [ ] 锚点节点命名正确（ROV 模型）
- [ ] 面数与贴图尺寸在预算内
- [ ] GLB 上传至 `public/models/...` 后 `npm run build` 无警告
