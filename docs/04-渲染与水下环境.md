# 04 — 渲染与水下环境

> 渲染层使用 Three.js（r160+）。本文档描述水下视觉效果的实现规范与性能预算。

## 1. 渲染总体策略（性能优先，ADR-008 相关）

- 目标：中低配电脑 60 FPS（无后处理）；提供"低/中/高"三档质量设置。
- **低档**：阴影关闭、粒子减半、雾使用 `FogExp2` 近似、灯光数减半。
- **中档**：开启 1 盏平行光阴影（2048）、标准粒子数量、`Fog` 指数雾。
- **高档**：增加体积光近似（God Rays 用平面渐变模拟，不做真实 volumetrics）、全粒子。
- 水下效果一律**不用**完整后处理链（UnrealBloom 等开销大），用材质/雾/灯光组合模拟。

## 2. 水下光线模型

### 2.1 光衰减（Beer–Lambert 近似）

- 在材质中用自定义着色器或 `onBeforeCompile` 注入：
```
I(d) = I0 * exp(-c * d)
c = attenuationCoeff = base(0.15) + turbidity * 0.8   // 吸收+散射系数
```
- **光谱吸收**：红光衰减最快，蓝绿穿透最强。用每通道系数：
```
c_r = c * 1.8;  c_g = c * 1.0;  c_b = c * 0.6;
```
- 远处物体整体偏蓝绿、变暗——这是水下"真实感"的最重要单一来源。

### 2.2 雾（Fog）

- 使用 `FogExp2` 或 `Fog`，密度/距离由 `visibility`（能见度）换算：
```
fogNear = visibility * 0.4;  fogFar = visibility * 1.6;
颜色取深海蓝绿色（随深度变深，如 HSL(200-220°, 40-60%, 8-20%)）。
```

### 2.3 光源

1. **太阳光（水面穿透）**：平行光，方向随 `sunlight` 参数与深度衰减；`lightFlicker` 时用低频噪声调制强度（水面波折射闪烁）。位置在场景上方，穿过水面照入。
2. **环境光**：低强度蓝色环境光，模拟水体散射。
3. **ROV 补光灯**：SpotLight，由机型配置定义数量/位置/功率；开关由 `lightsOn` 控制；灯光穿透距离受衰减系数 c 影响（距离远时光斑衰减）。水中补光产生"体积光锥"效果用半透明锥 mesh + additive 混合模拟（性能友好）。

### 2.4 浮游粒子（Marine Snow）

- `THREE.Points` 或 `InstancedMesh`，数量随质量档（低 800 / 中 1500 / 高 3000）。
- 粒子位置受水流场影响漂移：`p += (v_current + v_turb(p, t)) * dt`；超出范围回卷（torus 环绕）。
- 粒子受 ROV 灯光照亮（`PointsMaterial` 配合亮度变化，或用 shader 计算距离衰减）。

## 3. 场景管理（需求 R2）

### 3.1 场景接口

```ts
// render/scenes/BaseScene.ts
export interface SceneDefinition {
  id: string;                       // 'salvage' | 'dam' | 'ship' | 'bridge'
  name: string;                     // 中文名
  description: string;
  environmentDefaults: Partial<EnvironmentParams>;  // 场景默认环境
  build(world: THREE.Scene, assets: SceneAssets): void;  // 构建几何/光照
  update(dt: number, time: number, ctx: SceneContext): void; // 每帧
  dispose(): void;
}
```

- `SceneAssets`：内置资产库（岩石、海底地形、目标物、结构件基元），供各场景复用。
- 场景注册表：`src/render/scenes/registry.ts`，`registerScene(def)` / `getScene(id)`。

### 3.2 海底环境通用要素

- 海底地形：`PlaneGeometry` + 高度图（分形噪声）→ `BufferGeometry`，或用低模 mesh；材质用深色岩石贴图 + 顶点色变化（可程序化生成，无外部资源）。
- 目标物与作业对象：见 `06-机型场景与任务.md`。
- 场景边界：软边界（距离中心 > 500m 后显示"超出作业区"提示并施加回退推力，防学员漂丢）。

### 3.3 四个内置场景的设计要点

| 场景 | 地形/结构 | 目标物 | 环境默认 |
|------|-----------|--------|----------|
| 水下打捞 Salvage | 平坦泥地 + 岩石散落 | 沉船残骸、箱子、集装箱 | 流速 0.3 m/s、能见度 20m、浊度 0.3 |
| 大坝检测 Dam | 巨大混凝土坝面 + 垂直落差 | 坝面裂缝标记区、闸门、进水口格栅 | 流速 0.8 m/s（坝前）、能见度 30m |
| 船舶检测 Ship | 船体（龙骨、螺旋桨、船艏） | 船体附着物区域、螺旋桨 | 流速 0.5 m/s、能见度 15m |
| 桥梁检测 Bridge | 桥墩、承台、桥底 | 桥墩冲刷区、裂缝区 | 流速 1.0 m/s（桥墩附近局部增强）、能见度 12m |

- 每个场景包含**局部水流增强区**（如桥墩后涡流），实现方式：在 `SceneDefinition.update` 中向 `CurrentField` 注册 `LocalFlowZone`（位置 + 半径 + 流速增量 + 旋转），物理采样时叠加。

### 3.4 水流视觉化（可选加分项）

- 用粒子/纱线（Streamlines）或网格顶点偏移表现水流方向与强度（低性能档可关闭）。
- 悬浮物（如浊度高时的泥沙团）随局部流区运动，帮助学员"看到"水流。

## 4. 相机与视角（需求 R3）

详细见 `05-视角HUD与声纳.md`。渲染层职责：
- `CameraRig` 管理三种相机模式的切换与更新；
- 主渲染目标始终是活动相机；声纳视角是**覆盖式分屏/全屏**（同屏叠加或独立 viewport）。

## 5. 性能预算

| 项 | 低 | 中 | 高 |
|----|----|----|----|
| 像素比 | 1.0（限制 ≤ 1.0 可 0.75） | ≤ 1.5 | 设备原生（≤2） |
| 阴影 | 关闭 | PCFSoft 2048（平行光） | PCFSoft 2048 + 补光 1024 |
| 粒子数 | 800 | 1500 | 3000 |
| 雾 | FogExp2 | Fog | Fog + 材质注入衰减 |
| 灯光 | 1 平行 + 环境 | + ROV 补光 1 盏 | 全量 + 光锥伪体积光 |
| 后处理 | 无 | 无 | 仅色调（可选） |

- 每帧渲染层应报告 `fps` 与 `drawCalls`，低档下 drawCalls < 300 为目标。
- 场景大物件合并 mesh（`BufferGeometryUtils.mergeGeometries`），减少 draw call。
