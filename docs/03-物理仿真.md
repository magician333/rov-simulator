# 03 — 物理仿真（仿真核心）

> 本文档是 AI 开发者实现 `src/core/` 的规范。所有公式与约定以此为准。

## 1. 坐标系与姿态约定（重要，全项目统一）

### 1.1 世界坐标系（World）

- 使用 Three.js 默认右手系：**Y 向上**，X 东、Z 南（即"北"为 -Z 方向）。深度 = `-position.y`。
- 单位：米。

### 1.2 ROV 体坐标系（Body）

- 原点：ROV 重心（CoG）。
- **+X = 右侧，+Y = 上，+Z = 后方**（Three.js 惯例，模型前向为 **-Z**）。
- 体坐标系固定在刚体上，随 ROV 旋转。

### 1.3 姿态欧拉角（唯一约定，ADR-009）

```ts
rovObject.rotation.order = 'YXZ';
rovObject.rotation.x = pitch;  // 俯仰：抬头为正（+rad）
rovObject.rotation.y = yaw;    // 偏航：绕世界Y轴，从 -Z 向 +X 方向为正
rovObject.rotation.z = roll;   // 横滚：右侧下沉为正（+rad）
```

- **航向角** `headingDeg`：0-360°，从北（-Z）顺时针，0=北、90=东、180=南、270=西。
  由 `yaw` 换算：`headingDeg = (yaw * 180/PI + 180) % 360`（因为北=-Z，yaw 为正 → 转向 +X 即东，符合顺时针）。
- HUD 中俯仰/横滚显示角度（度），范围：pitch ∈ [-90, 90]，roll ∈ [-180, 180]。

### 1.4 速度/角速度

- **线速度 `v`**：世界坐标系（m/s），便于与水流场（世界系）做相对速度计算后转体坐标系计算拖曳力。
- **角速度 `ω`**：体坐标系（rad/s），便于刚体方程。
- 转换：`v_body = R^T * v_world`，`v_world = R * v_body`（R 为姿态旋转矩阵，Three.js `quaternion` 对应矩阵）。

## 2. 六自由度刚体动力学

### 2.1 状态向量

```
状态：p (位置, 世界系), q (四元数, 姿态), v (线速度, 世界系), ω (角速度, 体系)
```

### 2.2 平动方程（世界系表达，力先算在体系再转到世界）

```
F_body = F_thruster + F_buoyancy + F_gravity + F_drag + F_current + F_turbulence
F_world = R * F_body
a = F_world / m
v += a * dt
p += v * dt
```

其中重力在体坐标系中为常量：

```
F_gravity = R^T * (0, -m*g, 0)
```

### 2.3 转动方程（体坐标系）

```
τ_body = τ_thruster + τ_restoring + τ_drag_rot + τ_disturbance
α = I^-1 * (τ_body - ω × (I * ω))     // 可忽略 ω×Iω（低速），保留以求稳
ω += α * dt
q = integrateQuaternion(q, ω, dt)      // 用四元数更新避免万向锁
```

### 2.4 力与力矩清单

| 力 | 表达式 | 说明 |
|----|--------|------|
| 推进器推力 `F_thruster` | `B * u`（见 §3） | 各推进器推力合成，B 为配置矩阵 |
| 重力 `F_gravity` | `(0, -m*g, 0)` 转体系 | m = 干质量 |
| 浮力 `F_buoyancy` | `(0, +ρ*V*g, 0)` 作用于浮心 | 作用点 CoB ≠ CoG 时产生恢复力矩 |
| 恢复力矩 `τ_restoring` | `r_CB × F_buoyancy`（体系） | r_CB 为 CoG→CoB 向量 |
| 线性阻尼 `F_drag` | `-0.5*ρ*Cd_i*A_i*|v_rel_i|*v_rel_i`（每轴） | v_rel = v_body - v_current_body |
| 旋转阻尼 `τ_drag_rot` | `-D_ω * ω` | D_ω 为角阻尼系数（对角矩阵） |
| 水流拖曳 | 已并入 `F_drag`（用相对速度） | |
| 湍流扰动 `F_turbulence` | 噪声场采样（见 §5.3） | 低幅高频，模拟水流抖动 |

### 2.5 中性浮力设定

- 第一版 ROV 配置为**微正浮力**（`ρ*V ≈ m * 1.02`），模拟真实作业 ROV 的安全特性：断电自动上浮。
- 浮心在重心上方约 `0.15 m`（`r_CB = (0, +0.15, 0)` 体系，近似），提供静态稳定性（倾覆自动回正）。

### 2.6 一键水平姿态（Level Attitude，需求 R6）

- 触发后进入 `attitudeHoldActive` 状态：目标 `roll_target = 0`、`pitch_target = 0`，用 PID（或 PD）控制：
```
τ_roll = kp_r * (0 - roll) - kd_r * ω_roll
τ_pitch = kp_p * (0 - pitch) - kd_p * ω_pitch
```
- 叠加到 `τ_thruster`；深度与航向不做闭环（保持学员手动控制）。姿态误差 < 0.5° 时退出该状态。

## 3. 推进器配置与推力分配

### 3.1 配置矩阵（Thruster Configuration Matrix）

设 ROV 有 `n` 个推进器。每个推进器 i 有：安装位置 `r_i`（体坐标系）、推力方向单位向量 `f_i`（体坐标系）。则推进器力对 6DOF 的贡献为：

```
第 i 列：t_i = [ f_i
                r_i × f_i ]        (6×1)
配置矩阵：B = [t_1, t_2, ..., t_n]  (6×n)
```

总 6DOF 力/力矩：`[F; τ] = B * u`，其中 `u_i` 为第 i 个推进器的推力幅值（N）。

### 3.2 第一版 6DOF ROV 推进器布局（8 推进器）

推荐 **4 水平矢量推进器 + 4 垂直推进器**（经典布局，可实现全部 6 自由度独立控制）：

```
水平层（z≈0 平面）：
  T1: 位置(+Lf, 0, +W)  方向 (1, 0, 0)   # 右前，向前推力
  T2: 位置(+Lf, 0, -W)  方向 (1, 0, 0)
  T3: 位置(-Lb, 0, +W)  方向 (-1, 0, 0)  # 左后，向后推力
  T4: 位置(-Lb, 0, -W)  方向 (-1, 0, 0)
垂直层（z≈0 平面，或抬高）：
  T5: 位置(+Lf, 0, +W)  方向 (0, 1, 0)   # 上推力（下潜）
  T6: 位置(+Lf, 0, -W)  方向 (0, 1, 0)
  T7: 位置(-Lb, 0, +W)  方向 (0, 1, 0)
  T8: 位置(-Lb, 0, -W)  方向 (0, 1, 0)
```

- 其中 `Lf`（前推进器距重心的 x 距）、`Lb`、`W`（半宽）由 `ROVConfig.dimensions` 派生。
- 该布局通过伪逆分配可产生任意 6DOF 指令（满秩）。

### 3.3 推力分配算法（伪逆）

给定控制目标 `cmd = [F_x, F_y, F_z, τ_x, τ_y, τ_z]`（体坐标系 6DOF 力/力矩）：

```
u = B^T * (B * B^T)^-1 * cmd      # 右伪逆（n≥6 满秩时）
u = clamp(u, -u_max, u_max)       # 推进器推力上限
若 |u| 超出（饱和），按比例缩放保留方向：u *= u_max_sat / |u|_max
```

- 为减小伪逆产生的对顶推挤，可在分配后叠加二次规划修正（第一版不做，可留 TODO）。
- 每自由度指令来自 `ROVController`（见 §4）。

## 4. 控制输入 → 指令

### 4.1 输入通道（键盘映射，需求 R6）

| 按键 | 自由度 | 作用 |
|------|--------|------|
| W / S | Surge 纵荡（前/后） | 沿机身 -Z/+Z 方向（模型前向） |
| A / D | Sway 横荡（左/右） | 沿机身 -X/+X |
| Q / E 或 Space / Ctrl | Heave 垂荡（上浮/下潜） | 沿机身 +Y/-Y |
| ← / → | Yaw 偏航 | 左转/右转 |
| ↑ / ↓ | Pitch 俯仰 | 抬头/低头 |
| Alt+← / Alt+→（或 R/F） | Roll 横滚 | 左倾/右倾 |
| L | 补光灯开关 | 切换 ROV 灯光 |
| B 或 0 | 一键水平 | 触发姿态稳定（§2.6） |
| V（循环）/ 1/2/3 | 视角切换 | chase / pov / sonar |
| Esc | 暂停/打开菜单 | — |

> 所有按键在 `KeyMapping` 表配置，代码中**不写死按键**，便于后期改键。

### 4.2 控制律

采用**目标速度映射 + 比例控制**（比直接推力控制更稳、更易教学）：

```
指令轴 i：speed_cmd_i = keyAxis_i * v_max_i
其中 v_max_i 由 maxSpeedKnots 按自由度比例给出（前进轴达到 4.5 节上限）
力：F_cmd_i = kp_i * (speed_cmd_i - v_i_rel_body) + 前馈项
（第一版可简化为：F_cmd_i = keyAxis_i * F_max_i，即直接线性油门；
  手感调优阶段再切比例控制。）
```

**实现建议（第一版）**：直接 `F_cmd_i = keyAxis_i * F_max_i`（线性油门），简单、可控；`F_max_i` 取保证在无水流下最大前进速度≈4.5 节的标定值。

### 4.3 航速限制（4.5 节，需求 R6）

- 前进轴 `F_max_surge` 标定：`F_max = 0.5*ρ*Cd*Amax * (2.315 m/s)^2` 量级，保证极限速度≈4.5 节。
- 同时提供软限速：`if (v_forward > 4.5kn) 推进器前进指令按比例削减`。
- UI 面板可调目标航速上限 `maxSpeedKnots ∈ [0.5, 4.5]`（默认 4.5），调节时按比例缩放各轴 `F_max_i`。

## 5. 水流与湍流场（需求 R1）

### 5.1 环境参数（实时可调）

```ts
export interface EnvironmentParams {
  currentSpeed: number;        // 流速 m/s，范围 [0, 3]，默认 0
  currentDirectionDeg: number; // 流向（来自方向），0-360°，默认 0（朝南）
  turbulence: number;          // 湍流强度 0..1，默认 0.2
  visibility: number;          // 能见度 m，范围 [1, 60]，默认 25（渲染层雾参数）
  temperatureC: number;        // 水温 ℃，范围 [-2, 30]，默认 8（HUD 显示）
  turbidity: number;           // 浊度 0..1，默认 0.15（影响雾浓度与光照散射）
  sunlight: number;            // 水面光照强度 0..1，默认 0.8
  lightFlicker: number;        // 光照闪烁强度 0..1，默认 0.2
}
```

### 5.2 均匀流 + 垂直变化

- 基准流：`v_current_world = currentSpeed * (cos(dirRad), 0, sin(dirRad))`（世界系水平面）。
- 深度衰减（近底阻力）：`factor = clamp(1 - depthMeters / 400, 0.3, 1)`。
- 全局流向/流速变化立即进入物理计算（下一物理步生效）。

### 5.3 湍流扰动场

- 使用 **3D Value/Perlin 噪声**（轻量实现，禁依赖重型库），采样 `N(p, t)`：
```
v_turb(world) = turbulence * noise3D(p * freq + t * timeScale) * strength
```
- 作用：
  1. 物理：`F_turbulence = drag_coeff * (v_turb - v_body)` 小项（引起姿态轻微抖动）。
  2. 视觉：浮游粒子随流场漂移（渲染层）。
  3. 声纳：距离测量加抖动（声纳模块）。
- 噪声函数使用固定随机种子，保证可复现。

### 5.4 水流对 ROV 的影响

- 拖曳力使用相对速度：`v_rel_body = R^T * (v_world - v_current_world)`。
- 大流速下 ROV 需对抗水流，否则漂移——这是培训的核心教学点之一。

## 6. 数值积分

- **固定步长** `dt = 1/120 s`。
- 平动：半隐式欧拉（先更新 v 再更新 p），或 RK4（推荐，成本低且稳定）。
- 姿态：四元数积分：
```
ω_quat = (0, ω_x, ω_y, ω_z)
dq/dt = 0.5 * q * ω_quat
q += dq/dt * dt; q.normalize();
```
- 循环结构：

```ts
export class PhysicsLoop {
  private accumulator = 0;
  step(renderDelta: number) {
    this.accumulator += Math.min(renderDelta, 0.1); // 防螺旋
    while (this.accumulator >= FIXED_DT) {
      this.simulation.step(FIXED_DT);
      this.accumulator -= FIXED_DT;
    }
  }
}
```

- 最大追赶步数限制（如 8 步），防止 Tab 切回时爆炸。

## 7. 流体模拟增强（M24）

真实水域操作感提升，全部可调且不破坏既有手感：

| 项 | 实现 | 位置 |
|---|---|---|
| **附加质量** | 排开水体惯性：平动 `a = F / m_eff`（按体轴，heave 方向比例最大：standard 0.8 / M2S 0.55）；转动 `α = τ / I_eff`（`I_eff = I × (1 + ang)`） | `ROVConfig.addedMass`、`PhysicsWorld`、`RigidBody6.effInertiaBody` |
| **推进器一阶响应** | 真实推进器启动/响应延迟：每推进器推力一阶低通 `τ=0.12s`，加速更平滑 | `PhysicsWorld.thrustFilt` |
| **近底效应** | 距海底 <3m 时阻尼增强（垂向 ×2.2 最大、水平 ×1.5），近底操作更"粘" | `WaterForces.compute`（seabedHeight） |
| **湍流偏航扰动** | 水流涡流对 yaw 的干扰力矩（随湍流强度、随深度减弱），另有轻微俯仰/横滚扰动 | `PhysicsWorld.applyTurbulenceTorque` |
| **海况浅层涌浪** | 海况 >0 且深度 <8m 时湍流增强（近水面浪涌扰动更真实） | `CurrentField.velocityAt` |

验证：M2S 全油门仍 3.00 节、roll 2s 达 75° 限位、解锁悬停保持 10.00m、深水下潜 4.54kn（近底减速）、推进器响应速度平滑爬升（0.5s 达 2.65kn）。
