# ROV 操作模拟器 — 开发文档

> 本文档面向 **AI 开发者**，描述一个网页端三维 ROV（遥控水下机器人 / Remotely Operated Vehicle）操作模拟器（培训用途）的完整设计，作为开发实现的唯一依据。实现过程中如有歧义，以本文档为准；如需变更设计，先更新本文档再改代码。

## 1. 项目一句话

一个运行在浏览器中的 **三维 ROV 操作训练模拟器**：学员像操作真实 ROV 一样控制六自由度水下机器人，在可实时调节的海底水流/光线环境中完成水下打捞、大坝检测、船舶检测、桥梁检测等作业训练，支持第三/第一/声纳三种视角与完整驾驶 HUD。

## 2. 技术栈（已确认）

| 领域 | 选型 | 说明 |
|------|------|------|
| 3D 渲染 | Three.js（r160+，命令式封装） | WebGL 渲染，手写 Renderer 类而非 @react-three/fiber，物理/渲染循环与 React 解耦 |
| UI 框架 | React 18 + TypeScript | 只负责 HUD、控制面板、菜单等 UI，不直接操作 Three.js 场景 |
| 状态管理 | Zustand | 单一 store 桥接仿真核心与 UI；仿真核心状态也经由 store 同步给 HUD |
| 构建 | Vite | 静态站点，纯前端部署 |
| 物理仿真 | 自研简化水动力模型 | 六自由度刚体动力学 + 推进器推力分配 + 阻尼 + 水流扰动，固定步长积分 |
| 数据持久化 | localStorage | 设置、训练成绩历史；成绩支持导出 JSON |
| 无后端 | 是 | 纯前端静态部署，单页应用 |

## 4. 给 AI 开发者的实现顺序建议

严格按 `07-开发里程碑.md` 的 M1→M6 顺序实现，每个里程碑结束都有可运行的验收点。**不要跳过 M1 直接做 UI**；物理核心（M2）是所有后续功能的地基。

## 5. 全局约定（必须遵守）

- 单位：长度 **米（m）**、时间 **秒（s）**、质量 **千克（kg）**、力 **牛顿（N）**、角度 **弧度（rad，仅显示层转度数）**、速度显示 **节（kn，1 kn = 0.514444 m/s）**、温度 **摄氏度（℃）**、深度 **米（正值表示水深）**。
- 渲染帧率目标 60 FPS（低配 30 FPS）；物理步长固定 `1/120 s`，与渲染循环解耦。
- 所有数值时间依赖必须使用**固定物理步长**累积，禁止用 `requestAnimationFrame` 的 delta 直接驱动物理。
- 代码注释与变量命名使用英文；文档/UI 文案使用中文。
- 所有扩展点（场景、机型、任务）必须走注册表模式，禁止在核心代码中写死业务场景。
