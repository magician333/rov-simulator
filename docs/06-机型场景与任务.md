# 06 — ROV 机型、场景与任务扩展

> 本文档描述三类扩展点的接口规范：ROV 机型（自由度差异）、作业场景（注册表）、任务（状态机）。

## 1. ROV 机型配置（需求 R4）

### 1.1 类型定义

```ts
// core/rov/ROVConfig.ts
export type ThrustAxis = 'surge' | 'sway' | 'heave' | 'roll' | 'pitch' | 'yaw';

export interface ThrusterSpec {
  id: string;
  position: [number, number, number];  // 体坐标系，米
  direction: [number, number, number]; // 推力方向（单位向量，体坐标系）
  maxForce: number;                    // 最大推力 N
  minForce: number;                    // 最小推力（负 = 可反转）N
}

export interface LightSpec {
  id: string;
  position: [number, number, number];  // 体坐标系
  intensity: number;                   // 相对强度
  range: number;                       // 有效射程 m
  angle: number;                       // 光束角 rad
  color: number;                       // 0xRRGGBB
}

export interface ROVConfig {
  id: string;
  name: string;                        // 机型显示名
  description: string;
  model: { type: 'generated' } | { type: 'gltf'; url: string };  // 第一版 generated
  maxSpeedKnots: number;               // 最大前进航速
  massKg: number;
  displacementM3: number;              // 排水体积
  dimensions: { length: number; width: number; height: number };
  cogOffset: [number, number, number]; // 重心偏移（体坐标系）
  cobOffset: [number, number, number]; // 浮心偏移
  dragCoeffs: { lin: [number, number, number]; ang: [number, number, number] };
  thrusters: ThrusterSpec[];           // 推进器布局 → 决定自由度
  controllableAxes: ThrustAxis[];      // 可控制自由度（决定按键是否生效）
  lights: LightSpec[];
  povOffset: [number, number, number]; // 第一视角相机位置（体坐标系）
  sonar: SonarParams;                  // 声纳参数（机型相关）
}
```

### 1.2 自由度差异的实现

- **自由度差异 = 推进器布局差异 + `controllableAxes` 白名单**。
- 推进器配置矩阵 `B` 由 `thrusters` 自动生成（§03-3.1）；伪逆分配自然得到各轴可控性。
- `controllableAxes` 用于 UI/控制层：不在白名单的轴，键盘输入忽略、HUD 不显示对应控制项。
- 示例：
  - 6DOF 通用型：全部 6 轴可控（第一版内置）。
  - 4DOF 型（未来）：仅 surge/sway/heave/yaw（无 roll/pitch 主动控制，靠浮力恢复）。
  - 潜水器型（未来）：仅 surge/pitch/heave（无 sway/roll/yaw 主动控制）。

### 1.3 机型注册表

```ts
// core/rov/registry.ts
const registry = new Map<string, ROVConfig>();
export function registerRov(cfg: ROVConfig) { registry.set(cfg.id, cfg); }
export function getRov(id: string): ROVConfig | undefined { return registry.get(id); }
export function listRovs(): ROVConfig[] { return [...registry.values()]; }

// 内置注册
registerRov(DEFAULT_ROV_CONFIG); // rov_6dof_standard
```

- 主菜单机型选择：`listRovs()` 渲染列表；选中后显示自由度/尺寸/推进器数量/灯光数等参数卡片。

## 2. 代码生成 ROV 模型（第一版，需求："第一版先用代码生成一个ROV模型"）

### 2.1 模型构成（`render/rov/GeneratedROVModel.ts`）

- 完全由 Three.js 几何体组合，按 `ROVConfig` 参数化构建（尺寸、推进器数量/位置、灯光数量）。
- 组成部件：
  1. **主框架**：`BoxGeometry`（长×宽×高），中空感用四根边框柱 + 上下横梁（框架笼式 ROV 常见造型）。
  2. **浮力块**：左右两块浅色块（顶部），体现浮力材料。
  3. **推进器导管**：每个推进器一个 `CylinderGeometry` 导管 + 内部转子（旋转动画可选），按 `thruster.position`/`direction` 摆放。
  4. **电子舱**：主体中心的 `CylinderGeometry`（耐压壳），深色。
  5. **补光灯**：按 `lights` 位置放置发光小球 + SpotLight。
  6. **相机**：头部的 `BoxGeometry` 小摄像头块（POV 位置可视化）。
  7. **机械臂占位**（打捞场景相关，第一版可省略或简单管件）。
- 材质：主框深灰金属（`MeshStandardMaterial` + 粗糙度 0.6），浮力块黄色（高可见度，真实 ROV 常配色），耐压壳深蓝。
- 模型根节点：`Object3D`，统一 `rotation.order = 'YXZ'`，前向 -Z。

### 2.2 模型与物理位姿同步

- 渲染层每帧：`rovObject.position.copy(snapshot.position); rovObject.quaternion.copy(snapshot.quaternion);`
- 灯光开关：`lightsOn` → 点亮/熄灭 SpotLight 与发光小球 emissive。
- 推进器转动动画：按 `thrusterCommands[i]` 的绝对值驱动导管内转子旋转速度。

### 2.3 GLTF 模型扩展（后续）

- `model.type === 'gltf'` 时用 `GLTFLoader` 加载 `public/models/{id}/model.gltf`。
- 约定：模型根节点前向 = -Z，单位米，Y 向上；附件锚点（灯光/相机/推进器）用**命名空节点**（如 `light_main`、`pov_cam`、`thruster_1`）标记，渲染层按名字查找并挂载动态对象。
- 文档补充约定写入本文件的"模型规范"小节（供未来建模方阅读）。

## 3. 作业场景（需求 R2，注册表化）

- 场景接口见 `04-渲染与水下环境.md` §3.1（`SceneDefinition`）。
- 场景注册表：`render/scenes/registry.ts`。
- 每个场景文件（`SalvageScene.ts` 等）导出 `SceneDefinition` 并自注册。
- 主菜单场景选择从注册表读取；选择后 `SceneManager` 卸载旧场景、构建新场景、重置环境参数到 `environmentDefaults`、重置 ROV 位置到出生点。

### 3.1 出生点

- 每个场景定义 `spawn: { position, yawDeg }`（ROV 起始位置与朝向，通常离目标 30-50m）。

## 4. 任务系统（需求 R2 补充，简单任务闭环）

### 4.1 任务定义

```ts
// core/task/TaskDefinition.ts
export type TaskStatus = 'pending' | 'active' | 'completed' | 'failed';

export interface TaskStep {
  id: string;
  title: string;                        // 中文标题
  description: string;
  check(ctx: TaskContext): boolean;     // 完成判定
  optional?: boolean;
}

export interface TaskDefinition {
  id: string;
  sceneId: string;                      // 所属场景
  name: string;
  brief: string;                        // 任务简报（开始前显示）
  steps: TaskStep[];                    // 顺序步骤
  timeoutSeconds?: number;              // 可选限时（0=不限）
  onComplete?(ctx: TaskContext): void;  // 触发评分/奖励
  onFail?(ctx: TaskContext): void;
}
```

### 4.2 任务上下文与判定

```ts
export interface TaskContext {
  rov: ROVSnapshot;
  scene: SceneContext;                  // 场景内目标物位置/状态
  time: number;
  env: EnvironmentParams;
}
```

- 典型步骤判定示例（水下打捞）：
  1. `navigate`: ROV 到达目标物 5m 范围 → 显示"发现目标"。
  2. `approach`: 距离 < 1.5m 且相对速度 < 0.5 m/s → "接近完成"。
  3. `salvage`: 触发打捞按键/UI（模拟机械臂动作，第一版简化：靠近后长按 Space 3 秒）→ 目标上浮动画 → 完成。
- 步骤之间自动推进；当前步骤显示在 `TaskPanel`。

### 4.3 任务状态机

```ts
// TaskRunner
enum Phase { Idle, Active, Complete, Failed }
- Idle → Active: startTask(def)
- Active: update(ctx) 检查 steps[stepIndex]，完成则 index++
- 所有步骤完成 → Phase.Complete（记录耗时、触发 onComplete）
- 超时 → Phase.Failed（onFail）
- 任何状态 → reset() 回到 Idle
```

### 4.4 成绩记录（纯前端）

- 训练结束后生成 `TrainingRecord`：
```ts
interface TrainingRecord {
  id: string;             // uuid
  date: string;           // ISO
  rovId: string;
  sceneId: string;
  taskId: string;
  completed: boolean;
  durationSec: number;
  steps: { stepId: string; durationSec: number }[];
  maxDepthM: number;
  avgSpeedKnots: number;
}
```
- 存入 `localStorage`（`trainingStore`），主菜单"训练记录"页展示，支持导出 JSON。

## 5. 环境控制面板（需求 R1）

- 面板控件与 `EnvironmentParams` 一一对应（滑块/数字输入）：
  - 流速（0-3 m/s）、流向（0-360°）、湍流（0-1）、能见度（1-60 m）、温度（-2-30 ℃）、浊度（0-1）、光照（0-1）、闪烁（0-1）。
- 任何参数变化 → `store.setEnvParam` → `EnvironmentState.apply()`（下一物理步生效）→ 渲染层同步（雾/光/粒子/声纳衰减）。
- 面板显示"环境已修改"提示，可选"恢复场景默认"按钮。
