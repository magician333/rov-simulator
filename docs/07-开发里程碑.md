# 07 — 开发里程碑与验收标准

> AI 开发者按里程碑顺序实现。每个里程碑结束时应有可运行的验收点；验收通过后再进入下一个。

## M1 — 项目骨架与基础渲染（0.5-1 天）

**目标**：工程可运行，看到带水下效果的 3D 场景与代码生成 ROV 静态模型。

- [ ] Vite + React + TS 项目初始化；Three.js、Zustand 依赖安装。
- [ ] `Engine` 类：renderer/scene/camera 生命周期、渲染循环、resize 处理。
- [ ] 水下雾效（Fog）与基础光照（平行光 + 环境光）——此时可用默认场景（无作业对象）。
- [ ] `GeneratedROVModel`：按默认 `ROVConfig` 构建 ROV 网格，放置于场景中心。
- [ ] 基础 UI 壳：主菜单（机型/场景选择占位）→ 训练界面（canvas + 空面板）。

**验收**：`npm run dev` 打开，能看到蓝色水下背景 + 完整 ROV 模型（可绕模型观察）。

## M2 — 六自由度物理与操控（1-2 天）

**目标**：ROV 可开，手感基本成立。

- [ ] `PhysicsWorld` + `RigidBody6` + `WaterForces`（重力/浮力/阻尼/水流拖曳/扰动）+ `integrator`（RK4 或半隐式欧拉，固定步长 1/120）。
- [ ] `ThrusterAllocator`（配置矩阵 + 伪逆）。
- [ ] `ROVController`：键盘输入 → 6DOF 指令 → 推进器；航速限制 4.5 节。
- [ ] `ROVState` 快照与深度/航速换算。
- [ ] 一键水平姿态（PD 控制）。
- [ ] 调参：全油门前进达到 ~4.5 节；无输入时微正浮力自然上浮、姿态自稳。

**验收**：键盘 W/S/A/D/Q/E/方向键等能驱动 ROV 六自由度移动旋转；松开后漂移有阻尼感；`B` 一键回平；速度不超过 4.5 节。

## M3 — 视角系统与 POV HUD（1-2 天）

**目标**：三视角切换 + 第一视角完整 HUD（需求 R3/R5 主体）。

- [ ] `ChaseCamera`：中键拖动旋转、滚轮缩放（Blender 风格）。
- [ ] `POVCamera`：随 ROV 位姿固定。
- [ ] `ViewSwitch`：V / 1/2/3 切换。
- [ ] `PovHud`：迷你姿态模型（独立小 WebGL 画布）、罗盘、俯仰/横滚/速度（节）/深度/温度。
- [ ] HUD 数据由渲染循环节流写入 store（~10Hz）。

**验收**：三种视角可切换；POV 下 7 项参数全部实时正确；第三视角中键拖动旋转顺滑。

## M4 — 声纳系统（1 天）

**目标**：2D 扇形 FLS 声纳视角（需求 R3 声纳部分）。

- [ ] `SonarSimulator`：射线采样 + 图像生成（衰减/噪声/多径）。
- [ ] 声纳画布 `<canvas>` 渲染 + 量程/增益调节。
- [ ] 声纳视角切换与声纳 HUD。

**验收**：声纳视角能看到场景物体的扇形回波图像；调节量程/增益/噪声有实时反馈。

## M5 — 场景与任务系统（1-2 天）

**目标**：4 个作业场景 + 简单任务闭环（需求 R2、R4、R6 收尾）。

- [ ] 场景接口与注册表；4 个场景（打捞/大坝/船舶/桥梁）各含地形 + 目标物 + 局部水流区。
- [ ] 场景选择流程（主菜单 → 训练）。
- [ ] 任务定义与 `TaskRunner` 状态机；每场景 1 个默认任务。
- [ ] `TaskPanel` 与任务提示/完成/失败反馈。
- [ ] 训练成绩记录（localStorage）+ 记录页 + JSON 导出。

**验收**：4 个场景均可进入并完成默认任务；任务进度、完成评分、成绩记录可用。

## M6 — 机型配置化与收尾（1-2 天）

**目标**：机型系统完整化、GLTF 加载通道就绪、性能与打磨。

- [ ] 机型注册表 + 主菜单机型选择卡片（自由度/参数展示）。
- [ ] GLTF 模型加载通道（`model.type === 'gltf'`）与锚点约定实现。
- [ ] 环境实时调节面板完整（全部 8 参数 + 恢复默认）。
- [ ] 图形质量设置（低/中/高）+ 性能预算验证（低档 drawCalls < 300）。
- [ ] 按键说明面板（HelpPanel）；暂停菜单（Esc）。
- [ ] 构建部署：`npm run build` → 静态托管（任意静态服务器/GitHub Pages）。

**验收**：完整流程可用——选机型 → 选场景 → 训练（环境可实时调、三视角、任务完成）→ 查看成绩记录。

## 验收总清单（对应六大需求）

- [ ] R1：环境 8 参数实时调节，物理与渲染同步生效。
- [ ] R2：4 个场景可切换，注册表机制便于扩展。
- [ ] R3：三视角切换；第三视角中键拖动（Blender 风格）。
- [ ] R4：多机型选择（第一版 1 个内置 + 注册表）；补光灯开关。
- [ ] R5：POV 显示姿态模型/罗盘/俯仰/速度(节)/横滚/深度/温度。
- [ ] R6：灯光开关；航速调节（最大 4.5 节）；一键水平恢复。

## 风险与对策

| 风险 | 对策 |
|------|------|
| 伪逆推力分配产生对顶推力、效率低 | 若手感不佳，改用几何分配（水平 4 推进器合成 surge/sway/yaw 的解析式），留 TODO |
| 中键拖动在浏览器默认行为冲突 | 监听 `pointerdown` + `buttons === 1`（中键），`preventDefault`；对触摸设备提供替代（右键拖或 UI 摇杆） |
| 低配机器粒子/雾过重 | 质量档位（低/中/高）降级策略 |
| 声纳采样性能 | 降波束数/更新率（10Hz 或 5Hz）；用预计算深度图替换逐射线 Raycast |
| 模型单位/朝向不符 | 统一约定（-Z 前、米、Y 上），加载时校验并加调试可视化 |
