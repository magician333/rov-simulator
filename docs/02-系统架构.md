# 02 — 系统架构

## 1. 分层架构

```
┌─────────────────────────────────────────────────────┐
│  UI 层（React）                                      │
│  主菜单 / 机型选择 / 环境控制面板 / HUD / 任务面板 /   │
│  视角切换 / 设置面板                                  │
└──────────────┬──────────────────────────────────────┘
               │ Zustand store（唯一共享状态）+ 事件
┌──────────────▼──────────────────────────────────────┐
│  仿真核心（纯 TS，与渲染解耦，可单测）                  │
│  SimulationEngine                                    │
│   ├── PhysicsWorld       六自由度动力学积分            │
│   ├── ROVController      输入 → 目标推力/力矩 → 推进器  │
│   ├── ROVState           位置/姿态/速度/推进器状态      │
│   ├── EnvironmentState   水流/光线/温度/能见度          │
│   ├── SonarSimulator     FLS 声纳采样与成像            │
│   └── TaskRunner         任务状态机                    │
└──────────────┬──────────────────────────────────────┘
               │ 命令式调用 + 同步
┌──────────────▼──────────────────────────────────────┐
│  渲染层（Three.js 命令式封装）                        │
│  Engine / SceneManager / EnvironmentRenderer          │
│  ROVRenderer（含代码生成模型）/ CameraRig / SonarView │
│  UnderwaterEffects（雾/光衰减/粒子/补光灯）           │
└─────────────────────────────────────────────────────┘
```

**规则**：
- UI 层**只读** store 与调用 store actions；不直接触碰 Three.js 对象。
- 渲染层**只读**仿真核心状态（位置、姿态、环境参数）来摆场景；不反向写物理。
- 仿真核心不依赖 Three.js（类型上可独立单测）。
- 三者通过 `Zustand store`（低频状态，如菜单/参数/成绩）与 `每帧同步`（高频，如 ROV 位姿，由渲染层在渲染循环内直接读 `SimulationEngine.getRenderSnapshot()`）通信。

## 3. 数据流

### 3.1 每帧流程（60 FPS 目标）

```text
requestAnimationFrame
  ├─ PhysicsLoop（固定步长 1/120s，追赶模式）
  │    input(Keyboard/Gamepad) ─► ROVController
  │        ─► target force/torque (6DOF) ─► ThrusterAllocator
  │        ─► thruster forces ─► PhysicsWorld.step(dt)
  │        ─► ROVState 更新（位置/姿态/速度/角速度/深度/航速）
  │        ─► EnvironmentState（水流场采样 → 拖曳力/扰动）
  │        ─► SonarSimulator（按需更新）
  │        ─► TaskRunner.update()
  ├─ RenderLoop
  │    snapshot = engine.getRenderSnapshot()
  │    ROVRenderer.sync(snapshot)          # 摆 ROV 网格/灯光
  │    CameraRig.update(snapshot)          # 三种视角
  │    UnderwaterEffects.update(snapshot)  # 雾/光/粒子
  │    renderer.render(scene, camera)
  └─ UI 同步（节流 ~10Hz 或事件驱动）
       store.setHudData(engine.getHudSnapshot())
```

### 3.2 状态快照接口（渲染层与 UI 的唯一读入口）

```ts
// core/ROVState.ts
export interface ROVSnapshot {
  position: { x: number; y: number; z: number };   // 世界系，米
  quaternion: { x: number; y: number; z: number; w: number };
  euler: { roll: number; pitch: number; yaw: number }; // rad，YXZ 约定
  velocityWorld: { x: number; y: number; z: number };  // m/s
  speedKnots: number;                                  // 机身速度（节）
  depthMeters: number;                                 // 深度（正=水深）
  headingDeg: number;                                  // 航向 0-360
  thrusterCommands: number[];                          // 各推进器推力（-1..1 归一化）
  lightsOn: boolean;
  attitudeHoldActive: boolean;                         // 一键水平进行中
}

export interface HudSnapshot {
  speedKnots: number;
  depthMeters: number;
  headingDeg: number;
  pitchDeg: number;    // -90..90
  rollDeg: number;     // -180..180
  temperatureC: number;
  attitude: ROVSnapshot['quaternion']; // 供迷你姿态模型使用
}
```

## 4. 状态管理（Zustand）

```ts
// state/store.ts（示意）
interface AppState {
  screen: 'menu' | 'training';
  selectedRovId: string;
  selectedSceneId: string;
  viewMode: 'chase' | 'pov' | 'sonar';
  envParams: EnvironmentParams;      // 环境实时调节参数
  rovControls: { lightsOn: boolean; maxSpeedKnots: number };
  hud: HudSnapshot | null;
  taskState: TaskState | null;
  // actions
  startTraining(): void;
  setEnvParam<K extends keyof EnvironmentParams>(k: K, v: EnvironmentParams[K]): void;
  setViewMode(m: AppState['viewMode']): void;
  toggleLights(): void;
  levelAttitude(): void;
  // ...
}
```

- 高频 HUD 数据（`hud`）由渲染循环节流写入（约 10Hz），避免 React 重渲染风暴。
- 环境参数 `envParams` 写入 store 的同时立即同步到 `EnvironmentState`（仿真核心），物理与渲染下个步长生效。

## 5. 事件总线（可选但推荐）

- 用轻量事件总线（`EventEmitter` 或 Zustand 订阅）发布：`training:started`、`task:progress`、`task:complete`、`environment:changed`、`view:changed`。
- 渲染层与 UI 层各自订阅所需事件，避免组件间直接引用。
