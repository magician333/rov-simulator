# ROV 模拟器 — 水下机器人操作培训模拟器

基于网页的三维 ROV（遥控水下机器人）操作培训模拟器：六自由度物理操控、真实水下环境、多波束声纳成像、机械臂夹取、任务系统与可配置机型，全部在浏览器中运行。

技术栈：**Three.js + React 18 + TypeScript + Zustand + Vite**。纯前端静态站点，无需后端。

## 功能特性

- **六自由度物理**：前进/横移/升降/转向/俯仰/横滚，含浮力、阻力、推进器矢量分配（固定 1/120s 步长，防螺旋累积器）
- **8 个作业场景**：水下打捞、大坝检测、船舶检测、桥梁检测、油气平台、管道外巡检、管道内巡检、网箱检测（注册表可扩展）
- **2 种机型**：通用 6 自由度 ROV（3 节）与紧凑型 CHASING M2（3 节、8 矢量推进器、微正浮力）
- **多波束扇形声纳**：低频 120°×120 米（垂直 ±10°），高频 80°×40 米（垂直 ±6°）；增益/量程/噪声/配色可调；DME 测距声纳（5 向距离）
- **机械臂**：滚轮相机/抓手缩放，精细夹取（开口百分比、失败提示）
- **任务系统**：导航 → 靠近 → 动作（长按空格），成绩记录 + JSON 导出
- **环境模型**：海况/河流/自定义三模式 —— 流速/流向/湍流/能见度/温度/浊度/光照；DVL 多普勒测速（悬停保持）
- **三视角**：第三视角、第一视角 POV HUD（姿态/罗盘/深度/俯仰横滚网格/雷达声纳）、2D 扇形声纳面板
- **多语言**：简体中文 / English / Español —— 按浏览器语言自动切换，默认英文；单位制（米/英尺、℃/℉）
- **手柄**：完整 Xbox 风格映射 + 灵敏度三档
- **设置**：显示 / 环境 / 操作 / 其他，跨会话持久化

## 部署方法

### 环境要求

- Node.js **>= 18**（开发使用 Node 23）
- npm（随 Node 自带）

### 本地开发

```bash
npm install
npm run dev        # 启动开发服务器 → http://localhost:5173
```

### 生产构建

```bash
npm run build      # 输出静态文件到 dist/
npm run preview    # 本地预览构建产物
```

### 静态托管

本项目是**纯静态站点**，无需服务端运行时。将 `dist/` 目录内容部署到任意静态托管：

- **Nginx**

```bash
# 将 dist/* 复制到网站根目录，例如 /usr/share/nginx/html/rov-sim/
```

- **GitHub Pages**

```bash
npm run build
# 将 dist/ 内容推送到 gh-pages 分支（或使用 actions/upload-pages-artifact）
```

- **对象存储 / CDN**（S3、OSS、Cloudflare R2 等）：上传 `dist/` 并按静态网站托管即可。

> 提示：这是单页应用（单个 index.html），无需 History 路由配置，任意静态服务器开箱即用。

## 操作方法

### 键盘

| 按键 | 功能 |
|------|------|
| `W` / `Z` | 前进 / 后退 |
| `A` / `D` | 左移 / 右移（横移） |
| `Q` / `E` | 上升 / 下潜 |
| `↑` / `↓` | 下俯 / 上仰 |
| `←` / `→` | 左转 / 右转（航向） |
| `R` / `F` | 左横滚 / 右横滚 |
| `空格`（长按） | 动作（抓取 / 作业） |
| `X` | 抓取 / 释放 |
| `S` | 声纳面板开关 |
| `V` / `1` / `2` | 视角切换（第三视角 / 第一视角） |
| `B` | 一键水平 |
| `G` | 切换控制坐标系：机身 / 世界 |
| `L` | 灯光开关 |
| `P` | 功率档位 |
| `Esc` | 暂停 / 继续 |

### 手柄（Xbox 风格）

| 控件 | 功能 |
|------|------|
| 左摇杆 | 前后 + 旋转 |
| 右摇杆 | 平移 + 升降 |
| `LB` / `RB` | 俯仰 |
| `LT` / `RT` | 横滚 |
| `A`（长按） | 动作（抓取） |
| `B` | 灯光 |
| `X` 短按 / 长按 | 视角切换 / HUD 布局 |
| `Y` 短按 / 长按 | 一键水平 / 控制坐标系 |
| `Start` | 打开设置菜单 |
| `Back` 短按 / 长按 | 声纳开关 / HUD 布局 |
| 十字键 | 菜单导航（LB/RB 切换标签页） |

### 任务流程

1. 主菜单选择场景与机型，点击**开始训练**。
2. 查看任务简报（左上任务框）与声纳标记。
3. 借助声纳 / POV HUD 导航靠近目标。
4. 长按 `空格`（手柄 `A`）执行动作（如抓取集装箱、检测焊缝）。
5. 完成任务获得成绩 —— 自动保存在记录页（支持 JSON 导出）。

### 设置

点击 ⚙ 按钮（或手柄 `Start`），选择标签页：

- **显示**：声纳相关优先 —— 频率、增益、噪声、配色、HUD 布局、罗盘样式、图形质量
- **环境**：海况 / 河流 / 自定义三模式 —— 流速、流向（≥359.9° 为乱流模式）、湍流、能见度、温度、浊度、光照闪烁
- **操作**：DVL 启用、控制灵敏度（手柄）、功率档位
- **其他**：语言（中 / 英 / 西）、单位制（公制 / 英制）

```
scripts/       物理冒烟测试
```
